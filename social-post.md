# Social Media Post Template

## Caption structure

```
[Hook — one plain, honest sentence about what this post is about]

[1–2 sentences of real detail — what happened, what's available, what changed]

[Optional: a clear, single call to action — book, ask, learn more]

[Contact: freclean7@gmail.com or link]
```

## Example (service update)

```
FreClean now offers office cleaning in Léogâne.

Scheduled cleaning for shared spaces, desks, and restrooms — booked and confirmed the same way as our residential service.

Book a cleaning: [link] or message us directly.
```

## Example (Web3 education post)

```
New to Web3? Here's the short version:

FreClean now accepts Celo stablecoin payments through our partner CeloHT — alongside cash and card, never instead of them. A stablecoin holds a steady value, so what you pay doesn't change between checkout and confirmation.

Full explainer: [link to freclean-dapp Learn page]
```

## Rules

- Follow `../docs/08-brand-voice.md` — no hype language, no unverified superlatives.
- Follow `../docs/07-social-media-guidelines.md` for what can and can't be claimed.
- Use only approved logo/photo assets (`../docs/01-logo-usage.md`, `../docs/05-photography-guidelines.md`).
