# Logo Usage

## Primary logo

`assets/logo/freclean-logo-primary.jpg` — the circular FreClean mark: a house silhouette with cleaning bubbles, wrapped in a blue-to-green ring, with the "Fre Clean" wordmark below.

## What's needed but not yet produced

| Transparent PNG / SVG vector version | Not yet available |

| White/reversed version (for dark backgrounds) | Not yet available |
| App icon / favicon-cropped version | Not yet available |

Do not approximate these by squashing or recoloring the primary JPG in a way that distorts the mark — produce real versions before using the logo in a context the primary file doesn't fit.

## Clear space

Maintain clear space around the logo equal to at least the height of the house icon inside the mark, on all sides. Nothing else (text, other graphics, the edge of a page) should sit inside that space.

## Minimum size

Do not reproduce the logo smaller than 32px (digital) or 0.5in (print) in diameter — below that, the bubble and house detail become illegible.

## What not to do

- Don't stretch, skew, or rotate the mark.
- Don't recolor the ring gradient to colors outside the approved palette (`02-color-system.md`).
- Don't place the full-color logo on a busy photo background without a solid or blurred backing shape behind it.
- Don't recreate the wordmark in a different typeface — use the logo file itself, not a typed-out approximation, whenever the mark is required.
