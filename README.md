# FreClean Brand

FreClean's brand system: logo usage, color, typography, UI patterns, photography, packaging (pointer), social media, brand voice, and marketing templates.

This is the source of truth other repositories were built against — `freclean-website`, `freclean-admin`, and `freclean-dapp` already implement the color and typography system documented here. If a brand element needs to change, change it here first, then propagate to the consuming repos.

## Status

**Foundational assets exist; several formats are still missing** — see the asset gap tables in `docs/01-logo-usage.md` and `docs/05-photography-guidelines.md`. This repo documents what's real and what's still needed, rather than pretending a full asset library already exists.

## Brand summary

| Element | Value |
|---|---|
| Primary colors | FreClean Blue `#0B72B9`, FreClean Green `#2FAE60` |
| Accent | Sun Gold `#F4B93F` (sparing use only) |
| Typefaces | Space Grotesk (display), Inter (body), IBM Plex Mono (data) |
| Signature motif | The "wipe" — a diagonal blue-to-green gradient |

## Why this repo exists

Without a single documented brand source, every repository (and every future designer or agency FreClean works with) ends up reinventing colors, type, and tone slightly differently. This repo exists so that doesn't happen — and so brand consistency is a checkable fact, not a hope.
