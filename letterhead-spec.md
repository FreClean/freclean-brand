# Letterhead & One-Pager Layout Spec

For use when producing an official FreClean letter, investor one-pager, or printed handout (in `freclean-docs`, Word, or design software).

## Header

- Logo, top-left, minimum 0.75in tall — see `../docs/01-logo-usage.md` for the source file and clear-space rule.
- Company name in Space Grotesk 700, FreClean Blue Deep (`#084F80`).
- Tagline area (optional): Inter 400, Ink Soft (`#5B7A77`).

## Body

- Body copy in Inter 400, Ink (`#0F2A2E`), 11–12pt for print.
- Section headers in Space Grotesk 600.
- Any data (figures, SKUs, addresses) in IBM Plex Mono where it aids scanability — otherwise Inter is fine for print body text.

## Footer

```
FreClean · Léogâne, Ouest, Haiti
freclean7@gmail.com · +1 (849) 388-1969
```

Set in Inter 400, 9pt, Ink Soft, centered or left-aligned depending on layout.

## Color use in print

Use FreClean Blue and Green only as accents (a rule under a heading, a footer line, the logo itself) — keep body text in Ink on white/off-white for print legibility and lower-cost printing (avoiding full-bleed color).

## Where this is used

- Any formal Word document produced via `freclean-docs` or ad hoc for investor/partner communication.
- Printed handouts for the Entrepreneur Program (`freclean-entrepreneurship`) once produced.
