# Social Media Guidelines

## Status

FreClean does not yet have confirmed, active social media accounts documented in this repository. This document sets the rules for when those accounts launch, so posting starts consistent rather than needing correction later.

## Voice on social

Same voice as everywhere else — see `08-brand-voice.md`. Slightly more casual and conversational than the website, but never inflating claims for engagement (no "biggest," "first," or "#1" claims that aren't verified — see the realism principle in `freclean-docs`).

## Visual consistency

- Use the approved logo files (`01-logo-usage.md`) — never a screenshot-cropped or freehand version of the mark.
- Use brand colors (`02-color-system.md`) for any graphic overlays or templates.
- Real photography per `05-photography-guidelines.md` — no unrelated stock imagery presented as FreClean's own work or team.

## What to post

- Real completed jobs (with customer consent), real product updates, real entrepreneur program milestones.
- Educational content (e.g. cleaning tips, "what is Celo" style explainers reused from `freclean-dapp`'s Learn page) is encouraged.

## What not to post

- Specific figures (revenue, customer counts, transaction volume) that aren't already verified and published in `freclean-docs`.
- Entrepreneur income claims or testimonials framed as guarantees — see the no-income-guarantee principle in `freclean-entrepreneurship`.
- Any claim about a partnership, certification, or integration ahead of it being real (e.g. do not announce a CeloHT feature as live before `freclean-payment`'s Supported Assets Registry actually reflects it).
